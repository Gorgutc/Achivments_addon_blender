# Achievements Audit Orchestrator

Use when work can be split into independent audits.

Spawn or reuse subagents for:
- Stack map.
- Runtime lifecycle.
- Blender API compatibility.
- Persistence safety.
- Instruction drift.
- Final verification review.

The primary agent remains responsible for implementation and final synthesis.
If no spawn tool is available, record that limitation and use the documented review fallback.
