## Примечания по реализации

### stat-достижения
Используют прямое сравнение значения из базы данных пользователя:
- `vertices_created` — счётчик всех когда-либо созданных вершин
- `vertices_deleted` — счётчик всех удалённых вершин
- `edges_created` — счётчик всех созданных рёбер
- `faces_created` — счётчик всех созданных граней
- `meshes_1000plus` — количество отдельных мешей, которые когда-либо имели 1000+ вершин
- `materials_applied` — количество применённых материалов
- `time_spent` — суммарное время (в секундах) открытого Blender
- `renders_completed` — количество успешно завершённых рендеров *(новый стат)*

### complex-достижения — описание проверок состояния сцены

| complex_id | Что проверять |
|-----------|--------------|
| five_modifier_stack | `len(obj.modifiers) >= 5` для любого объекта в сцене |
| mirror_subdivision | Объект имеет модификаторы типов `MIRROR` и `SUBSURF` одновременно |
| boolean_master | Объект имеет модификатор типа `BOOLEAN` с операцией DIFFERENCE или UNION |
| array_circle | Объект имеет `ARRAY` + `EMPTY` в качестве объекта смещения (offset_object is not None) |
| solidify_bevel_combo | Объект имеет модификаторы `SOLIDIFY` и `BEVEL` одновременно |
| screw_modifier | Объект имеет модификатор `SCREW` |
| ten_modifier_stack | `len(obj.modifiers) >= 10` для любого объекта в сцене |
| shrinkwrap_use | Объект имеет модификатор `SHRINKWRAP` с target != None |
| armature_modifier | Объект имеет модификатор `ARMATURE` с object != None |
| curve_deform | Объект имеет модификатор `CURVE` с object != None |
| skin_modifier | Объект имеет модификатор `SKIN` |
| weighted_normals | Объект имеет модификатор `WEIGHTED_NORMAL` |
| ten_lights_scene | `len([o for o in scene.objects if o.type == 'LIGHT']) >= 10` |
| three_light_setup | Сцена содержит минимум 3 источника света разных типов (SUN/POINT/SPOT/AREA) |
| hdri_lighting | World shader использует нод Environment Texture с загруженным изображением |
| depth_of_field | `camera.data.dof.use_dof == True` и `camera.data.dof.focus_object != None` |
| motion_blur_render | `scene.render.use_motion_blur == True` при последнем рендере |
| cycles_caustics | `scene.cycles.caustics_reflective or cycles.caustics_refractive` + объект с Glass/Transmission |
| volumetric_render | Материал любого объекта содержит нод `Volume Scatter` или `Volume Absorption` |
| compositing_node_render | `scene.use_nodes == True` и в compositor-графе есть ноды (кроме Input/Output) |
| render_passes | Включено `>=5` View Layer passes (diffuse_direct, specular_direct, shadow и т.д.) |
| denoiser_render | `scene.cycles.use_denoising == True` |
| principled_bsdf_full | Principled BSDF нод имеет подключённые сокеты: Base Color, Metallic, Roughness, Normal, Specular |
