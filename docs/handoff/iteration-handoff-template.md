# Iteration Handoff Template

Use this template at the end of every implementation iteration. Keep it factual and short enough that a fresh agent can resume without rereading the entire chat.

## Goal

State the iteration name and the concrete objective.

## Changed Files

List every tracked file changed in this iteration.

## Done

Summarize completed work and behavior that is now covered.

## Remaining

List unfinished work and the next intended iteration.

## Verification

List commands run, exit status, and important output summaries. Include skipped checks and why.

## Agents And Review

List spawned/reused agents, their role, and review result. Include `/review` or fallback result.

## Blockers

List blockers that prevented completion. Write `None` if there are no blockers.

## Residual Risks

List known risks that are not blockers but matter for the next session.

## Next Start Prompt

Provide the exact concise prompt a future session can use to continue.
