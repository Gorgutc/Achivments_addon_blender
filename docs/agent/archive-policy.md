# Archive Policy

The repository currently has a tracked duplicate add-on file. Do not delete or move it during preparation-only work.

Future archive decisions should preserve:
- The canonical source file selected by maintainers.
- A clear migration note explaining why the duplicate was archived or removed.
- A verifier update that stops requiring duplicate hash equality after the duplicate is intentionally removed.
- Any historical notes needed to reconstruct old achievement IDs.

Never archive real user progress data from `~/BlenderAchievements` into the repository.
